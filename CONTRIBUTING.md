# Участие в разработке

EllenSings — маленький pet-проект, но любые улучшения приветствуются.
Ниже короткие правила, чтобы PR проходили быстрее.

Все issues и обсуждения:
https://github.com/cofedish/EllenSingsBot/issues

## Багрепорты

Перед созданием issue:

1. Убедитесь, что у вас последняя версия (`git pull` и пересборка
   образа, если используете Docker).
2. Проверьте, нет ли похожего открытого issue.
3. Для проблем с воспроизведением прикладывайте:
   - версию Python / образ Docker;
   - фрагмент `logs/bot.log` (минимум 20 строк вокруг ошибки);
   - команду, которая привела к проблеме;
   - настройки прокси, если он включён (без самих учётных данных).

## Pull requests

- Ветка по умолчанию — `master`. PR отправляйте на неё.
- Держите PR сфокусированным: одна тема — один PR.
- Перед коммитом прогоните `python -m compileall bot.py cogs utils`
  чтобы убедиться, что нет синтаксических ошибок.
- Не коммитьте `.env`, токены Discord, файлы из `sounds/` большого
  размера и содержимое `tun2socks/`.

## Стиль кода

- Python 3.11+, 4 пробела, UTF-8, LF.
- Длина строки — мягкий лимит 100 символов.
- Для новых cog'ов придерживайтесь структуры существующих в `cogs/`.

## Лицензия

Отправляя вклад, вы соглашаетесь, что он распространяется на
условиях лицензии проекта.
