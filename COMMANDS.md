# EllenSings - Команды музыкального бота 🎵

> **Доступ:** команды управления воспроизведением (`/skip`, `/stop`, `/pause`,
> `/resume`, `/clear`, `/repeat`) и кнопки панели доступны только участникам
> того же голосового канала, где находится бот. `/play`, `/search` и
> `/playlist` требуют находиться в голосовом канале.

## 🎧 Основные команды

### `/play <запрос или URL>`
Включить музыку. Принимает поисковый запрос или прямую ссылку YouTube.
- **Автоматически показывает панель управления** с кнопками
- Поддерживает поиск по названию трека
- Добавляет трек в очередь

**Примеры:**
```
/play Imagine Dragons Believer
/play https://www.youtube.com/watch?v=...
```

### `/search <запрос>`
**НОВОЕ!** Интерактивный поиск треков с выбором из списка
- Находит до 10 результатов
- Красивое меню с превью треков
- Выбор через dropdown menu
- Показывает длительность и автора

**Пример:**
```
/search дота 2 музыка
```

### `/playlist <URL плейлиста>`
**НОВОЕ!** Добавить весь YouTube плейлист в очередь
- Загружает до 50 треков
- Показывает прогресс загрузки
- Автоматически начинает воспроизведение

**Пример:**
```
/playlist https://www.youtube.com/playlist?list=...
```

## ⏯️ Управление воспроизведением

### `/skip`
Пропустить текущий трек

### `/pause`
Приостановить воспроизведение

### `/resume`
Возобновить воспроизведение

### `/stop`
Остановить воспроизведение и очистить очередь

---

## 📃 Очередь треков

### `/queue`
Показать очередь треков с пагинацией
- Показывает текущий трек
- Список следующих треков (по 8 на страницу)
- Навигация по страницам

### `/clear`
Очистить очередь (текущий трек продолжит играть)

---

## 🔁 Режимы воспроизведения

### `/repeat [mode]`
Установить режим повтора
- `none` - без повтора
- `track` - повтор текущего трека
- `queue` - повтор всей очереди

**Примеры:**
```
/repeat track
/repeat queue
/repeat none
```

---

## 🎛️ Панель управления

После команды `/play` автоматически появляется интерактивная панель с кнопками:

### Первый ряд:
- **⏯️ Play/Pause** - пауза/возобновление
- **⏭️ Skip** - пропустить трек
- **⏹️ Stop** - остановить всё
- **🔁 Repeat** - переключить режим повтора
- **🔀 Shuffle** - перемешать очередь

### Второй ряд:
- **📃 Queue** - показать очередь
- **🔊 Volume +** - увеличить громкость
- **🔉 Volume -** - уменьшить громкость

## 💡 Полезные советы

1. **Быстрый старт**: Просто используйте `/play` - панель управления появится автоматически!

2. **Плейлисты**: Загружайте целые плейлисты одной командой `/playlist`

3. **Поиск**: Используйте `/search` когда не знаете точное название трека

4. **Shuffle**: Нажмите кнопку 🔀 для перемешивания очереди

5. **Громкость**: Регулируйте громкость кнопками 🔊/🔉 (0-200%)

6. **Repeat**: Циклично переключайте режимы повтора кнопкой 🔁
